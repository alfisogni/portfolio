\## UX Principles



The user must feel guided.



The user must never feel trapped.



The experience should reward exploration.



Information must remain accessible.



Beauty must never reduce usability.



The portfolio must work both as:



\* A professional portfolio

\* A narrative experience



\---



\## Golden Rule



Emotion first.



Information second.



Confusion never.
