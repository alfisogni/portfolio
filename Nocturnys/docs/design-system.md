\# Nocturnys - Design System



\## Design Philosophy



A quiet night library.



A hidden observatory.



A workshop illuminated by purpose.



Every component must feel intentional.



\---



\## Visual Principles



Minimalism



Layering



Atmosphere



Depth



Motion



Negative Space



\---



\## Color Philosophy



Primary:

Deep Blue



Secondary:

Night Black



Accent:

Starlight White



Supporting:

Forest Green



Rare Accent:

Cyan



\---



\## Typography



Large titles



Clean body text



Readable interfaces



Elegant hierarchy



\---



\## Shapes



Sharp



Architectural



Intentional



No excessive rounding



\---



\## Motion Principles



Everything moves with purpose.



Nothing moves for attention.



Motion should guide.



Motion should never distract.



\---



\## Interface Philosophy



Not a dashboard.



Not a SaaS.



Not a game.



Not a clone of Persona.



A symbolic space.



\---



\## Component Categories



Architectural



Navigation



Storytelling



Interactive



Atmospheric



\---



\## Quality Standard



Every screen should work as a wallpaper.



Every interaction should feel natural.



Every section should tell a story.
